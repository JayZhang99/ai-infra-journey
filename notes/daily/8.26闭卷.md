Autograd 定点补测

1. grad_fn 与 .grad 的职责差异是什么？

   grad_fn 是生成non-leaf tensor的函数

   .grad 是指tensor的梯度

2. non-leaf 保留 .grad 的正确接口是什么？

   retain_grad()

3. retain_graph 保存什么？

   保存Forward 图用于下一次backward 计算grad

4. create_graph 为什么能支持 HVP？

   因为新生成了graph 能够支持再求导计算一次梯度

5. y shape=[4] 时，backward 的 gradient 应是什么 shape？

   [4]

6. 写出 VJP 的 shape 链。

   x = [m,m]

   y = [n,n]

   v = [n,m]

   J = [m,n]

7. retain_graph=True 是否意味着 .grad 不累积？

   不是，retain_graph是保存forward graph,和.grad 是否累积没有关系

FLOPs 闭卷计算

1. M=64,N=128,K=256，约多少 FLOPs？

   2 * 64 * 128 * 256  =4,194,304 

2. N=512 方阵，写出 2*N^3 的完整结果。

   2 * 512 * 512 * 512 =268,435,456  

3. N 从 1024 变为 2048，FLOPs 变几倍？

   N 变两倍， FLOPS变8倍

4. 2.147 GFLOPs 在 0.2 ms 内完成，约多少 TFLOPS？

   （2.147 / 1000）TFLOPS / （0.2 / 1000）s = 10.735 TFLOPS

5. 为什么 TFLOPS 不能替代 median/p95？

​	这个只能代表处理的平均速度，不能像median描述一半人的延迟感知或p95百分之九十五的人的感知





Overlap 闭卷检查

1. pinned memory 为什么有利于 H2D？

   因为pinned memory可以用DMA实现异步

2. non_blocking=True 是否保证 overlap？

   不能，这是充分条件但不是必要条件，还需要pinned_memory 以及没有同步打断的操作比如.item

3. 同一 Stream 的 copy 和 compute 能否重叠？

   不能，同一Stream依旧按顺序

4. 列出真正 overlap 的三个必要条件。

   pinned_memory

   多个Stream

   non_blocking = True

5. event.synchronize 与 stream.wait_event 谁阻塞 CPU？

   event.synchronize 阻塞CPU

   stream.wait_event 只等待CUDA

6. 为什么 H2D+compute 不能与 compute-only 混比？

   关注点不一致，边界不同自然不能混比
