Overlap 闭卷检查

1. pinned memory 为什么有利于 H2D？

   因为pinned memory可以用DMA实现异步

2. non_blocking=True 是否保证 overlap？

   不能，这是充分条件但不是必要条件，还需要pinned_memory 以及没有同步打断的操作比如.item

3. 同一 Stream 的 copy 和 compute 能否重叠？

   不能，同一Stream依旧按顺序

4. 列出真正 overlap 的三个必要条件。

   pinned_memory

   多个Stream

   non_blocking = True

5. event.synchronize 与 stream.wait_event 谁阻塞 CPU？

   event.synchronize 阻塞CPU

   stream.wait_event 只等待CUDA

6. 为什么 H2D+compute 不能与 compute-only 混比？

   关注点不一致，边界不同自然不能混比
