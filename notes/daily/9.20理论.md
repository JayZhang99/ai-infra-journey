1. reduce_sum [2,3] -> []` 的 backward 为什么是 `[] -> [2,3]`，而

不是再 sum？

​	因为 y 对于所有x的导数都是1，所以需要广播到输入维度[2,3],再sum依旧是标量

• 2. 从 Python `load()` 到 CUDA kernel 执行，写出完整分层链路。

​	load -> 编译 生成object -> 链接 生成shared_library .so->  加载 -> dispatcher -> kernel 

• 3. 用 disk cache 与 process loaded 两个维度定义

cold/warm/loaded。

​	cold disk cache not prosess loaded not

​	warm disk cache exist process loaded exist

​	loaded disk cache not process loaded exist

• 4. ExtensionVersioner 与 Ninja 各自决定什么？

​	ExtensionVersioner 决定编译选项，sources

​	Ninja 决定 编译工具版本

• 5. API/ABI 分别处于什么层？为什么 API 不变仍可能 undefined

symbol？

​	API属于接口层，主要关注接口是否变化

​	ABI 主要关注符号是否变化，是否能正常加载

​	API 不变，如果torch 版本或nvcc版本变了， 同样可能影响符号，需要重编

• 6. `nm -D -C`、`DT_NEEDED`、`ldd`、Dispatcher 表和 smoke 各能

证明什么？

​	nm -D -C 可以证明接口是否已编译

​	DT_NEEDED

​	ldd 证明库是否链接

​	Dispatcher 证明是否注册到进程

​	smoke证明接口功能是否正确
