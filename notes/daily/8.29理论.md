1. 为什么历史 K/V 可以缓存，而历史 Q 不需要缓存？（2）

   历史Q 是生成历史output 需要的，当前decode 时历史输出已经有了，

   所以不需要缓存历史Q，但当前decode 的Key 和Value都需要历史K，V

2. pageable 与 pinned Host memory 的关键区别是什么？（2）

   pageable是可以被CPU换出去的页内存

   Host memory 为不被交换的固定内存

3. `non_blocking=True` 为什么不等于传输已完成？（2）

   这个只是代表传输可以异步进行，不代表传输完成

4. 不同 CUDA Stream 为什么不保证任务一定重叠？（2）

   不一定 non_blocking = True , 也不一定pinned memory，还不一定依赖，同步好

5. H2D 与 compute overlap 至少需要哪些条件？（2）

   H2D 和 compute在不同 stream

   pinned_memory, non_blocking = True,

   没有item,等同步操作

6. Profiler full/light 实验中唯一应该改变什么？（2）

   改变graph_memory 和另一个参数，其他完全一致
