1. persistent Buffer 如何保存、迁移和更新？

   随state_dict保存、迁移，更新通常不由优化器step更新，而是像通过running_stats独自更新

2. grad_fn 与 .grad 分别表示什么？

   grad_fn 表示生成non-leaf tensor 的函数

   .grad 代表tensor 的梯度

3. non-leaf 怎样保留梯度？

   retained_grad 接口

4. retain_graph 与 create_graph 各解决什么？

   retain_graph 解决需要累积两次梯度

   create_graph 新创建图用于求二阶导

5. 非标量 backward 的 gradient 参数是什么？

   微分矩阵

6. HVP 为什么比完整 Hessian 可扩展？

   因为完整Hessian 需要N *N 的空间，HVP只需要N得空间

7. M=N=K=512 时 MatMul 约有多少 FLOPs？

   512*512*512*2 =1,025,025,024 

8. 为什么 CUDA Python 返回时间可能不是 GPU latency？

   Python返回只是launch提交，不代表GPU Kernel完成

9. compute-only 与 H2D+compute 能直接比较吗？

   不能直接比较，H2D会有额外开销

10. Profiler 为什么不能代替 Benchmark？

    Benchmark代表的边界最坏结果，不能用Profiler替代



概念题：20 分

2 分：为什么 CUDA Python 返回不等于 GPU 完成？

​	因为CUDA python只代表提交Launch，不代表GPU 异步完成

2 分：同一 Stream 与不同 Stream 的顺序保证有何区别？

​	同一Stream默认按顺序，不同Stream需要同步通信保证

2 分：同步墙钟与 CUDA Event 分别测什么？

​	同步墙钟测 端到端

​	CUDA Event只测计算开销

2 分：为什么 Event 读取前必须等待 end Event？

​	因为不等待异步完成则又会偏小

2 分：`.item()` 为什么可能改变 CUDA 性能测量？

​	因为.item() 会导致等待完成，影响性能

2 分：compute-only 与 H2D+compute 有何区别？

​	compute-only 只关注计算部分

​	H2D+compute 还关注从CPU 转移到GPU的消耗

2 分：pinned memory 为什么有利于 H2D？

​	因为这一份上锁的内存只给GPU使用

2 分：non_blocking=True 是否保证 copy/compute 重叠？

​	不一定保证

2 分：Benchmark 与 Profiler 的职责差异是什么？

​	Benchmark是整体的性能边界

​	Profiler是过程中的耗时

2 分：为什么 Profiler 时间不能当最终 latency？

​	因为这只是过程中
