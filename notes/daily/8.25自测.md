1. persistent Buffer 如何保存、迁移和更新？

   随state_dict保存、迁移，更新通常不由优化器step更新，而是像通过running_stats独自更新

2. grad_fn 与 .grad 分别表示什么？

   grad_fn 表示生成non-leaf tensor 的函数

   .grad 代表tensor 的梯度

3. non-leaf 怎样保留梯度？

   retained_grad 接口

4. retain_graph 与 create_graph 各解决什么？

   retain_graph 解决需要累积两次梯度

   create_graph 新创建图用于求二阶导

5. 非标量 backward 的 gradient 参数是什么？

   微分矩阵

6. HVP 为什么比完整 Hessian 可扩展？

   因为完整Hessian 需要N *N 的空间，HVP只需要N得空间

7. M=N=K=512 时 MatMul 约有多少 FLOPs？

   512*512*512*2 =1,025,025,024 

8. 为什么 CUDA Python 返回时间可能不是 GPU latency？

   Python返回只是launch提交，不代表GPU Kernel完成

9. compute-only 与 H2D+compute 能直接比较吗？

   不能直接比较，H2D会有额外开销

10. Profiler 为什么不能代替 Benchmark？

    Benchmark代表的边界最坏结果，不能用Profiler替代
