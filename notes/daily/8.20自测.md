定点复测

1. Runtime 与 Serving 的职责边界是什么？

   Runtime 是指拿到输入调用模型获取输出，涉及模型选择、算子、调度，Serving的职责有网络、序列化/反序列化，队列

2. Operator 与 Kernel 为什么不是一一对应？

   有可能一个Operator 中的多个操作由多个Kernel执行

   也有可能多个Operator合并在一个Kernel执行

3. Concurrency 增大后，为什么 Queue Time 和 p99 可能上升？

   Concurrency代表堆积的请求，增大后可能导致高于吞吐，从而导致Queue Time和p99的上升

4. Queue Time 上升、Compute Time 不变，能够说明什么，不能说明

什么？

​	能够说明模型计算没有劣化，但不能说明是除了模型计算外的哪个具体部分出现问题，可能是队列、调度、Batch Size等等

5. 有界队列至少解决哪 4 个工程问题？
   1. 内存不会无限增长
   2. 请求不会一直堆积
   3. 避免积压





上班闭卷



1. Linear 的 weight 为什么是 [out,in]，输出如何计算？

   因为input 和 weight的转置进行矩阵乘法，所以weight为 [out,in]，

   假设input 为[B,in], 则输出为[B,out]

2. 两层 Linear 中间没有激活函数，为什么仍等价于一层？

   因为Linear只是线性操作，套两层也是线性操作，相当于一次Linear，

   必须增加激活函数变为非线性

3. Parameter 与普通 Tensor 的核心区别是什么？

   Parameter为模型中可训练改变的数据，普通Tensor不会被改变

4. loss.backward() 与 optimizer.step() 分别做什么？

   backward 后向转播算grad

   step则根据grad调整parameter

5. 为什么通常在每轮开始调用 zero_grad()？

   因为梯度会累积，不清零的话就会越来越大

6. state_dict 包含什么？为什么它不是完整模型程序？

   包含Parameter，和所有可学习的参数

   完整的模型程序还有环境，Python文件之类的东西

7. model.eval() 会自动关闭梯度吗？

   会关闭梯度

8. no_grad() 与 inference_mode() 的共同点是什么？

   都不会计算梯度

9. 输入 [16,8] 经过 Linear(8,32) 后 shape 和参数量是多少？

   [16,32], 参数量 8*32+32 =288
