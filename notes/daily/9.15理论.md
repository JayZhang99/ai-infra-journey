1. 写出 Baseline/Block 的 row 与 grid.x。

   Baseline row = BlockIdx.x * BlockDim.x + ThreadIdx.x grid.x = (rows + blockDim.x -1) / blockDim.x

   Block row = BlockIdx.x grid.x = rows

2. 逐字写出跨 Warp Reduction 的写者、Shared 槽、Barrier、读者。

   Warp Reduction

   写者 各warp lane 0， shared 槽：各warp lane0，Barrier 等待warp lane 0 写完，读者，其他warp

   写者 warp 0 lane 0， shared槽：warp 0 lane0，Barrier 等待 warp 0 lane 0 写完，读者

3. 50 repeats、100 launches/sample 时，p95 对什么样本求？

   p96是 50次repeat里面的95%数据，而并非 每一个repeat 的 100launch里的p96
