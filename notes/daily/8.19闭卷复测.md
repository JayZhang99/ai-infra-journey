1. Runtime 与 Serving 各自负责什么？为什么不能把边界简单说成序列

化？
 Runtime 负责调用模型输出结果，Serving负责用户输入收集，反序列化，排队，到推理结果的序列化和输出，因为序列化是Serving负责的一部分，不是边界

1. Operator 与 Kernel 为什么不一一对应？分别举两个方向的例子。
    可能出现一个Operator 由多个Kernel完成
    也有可能出现多个Operator合并由一个Kernel完成
2. Latency 和 Throughput 分别描述什么？
   1. Latency指的是延迟，是指响应的速度，是一个快慢的概念
   2. Throughput是指吞吐，是指系统处理请求的容量

5. 动态批处理为什么需要最大等待时间？
6. 因为如果没有最大等待时间的花，Batch等待就有概率变得很大，从而导致系统的延迟变大
7. 为什么平均延迟不能代替 p95/p99？
    因为平均延迟受极端值的影响很大，不能准确反映系统的延迟感受
8. Queue Time 上升但 Compute 不变，能够说明什么，不能说明什么？
    1能够说明除了模型计算部分有部分劣化，可能是排队，可能是Batch，也可能是序列化反序列化，但不能说明是哪一部分出了问题
9. 为什么在线请求队列必须有界？至少说出 4 个作用。
    1.有界保证输入请求不会无限增长导致超过系统处理能力极限
   2. 有限保证不会积压
10. TTFT、TPOT、ITL 分别反映什么？
11. TTFT --> Time take first token 第一个Token输出的时间
12. TPOT --> Time per output token 第一个Token输出后每个Token的时间
13. ITL --> Internal time   每个Token之间的时间间隔
14. 为什么性能报告必须记录硬件、软件、shape、dtype 和 Batch Size

？
 因为不同的硬件软件shape dtype Batch Size下，系统的表现就是会不同的，只有确定这些变量才能准确判断性能变化
