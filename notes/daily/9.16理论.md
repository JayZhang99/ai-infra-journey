1. TensorImpl 与 Storage 分别保存什么？transpose 为什么通常不复制

数据？

​	TensorImpl 保存数据解释，包括 dtype,device, shape,layout

​	Storage 保存 数据存放物理位置

​	transpose 只改变数据解释，所以不用复制数据

4. Schema 为什么不是 CPU/CUDA selector？真正的分派依据是什么

？

​	Schema只规定输入、输出数据格式

5. CUDAGuard 与 current stream 分别解决什么问题？

   CUDAGuard 解决 多GPU问题

   current stream 解决 生产者 kernel 消费者的顺序问题

6. 跨 Warp Reduction 的写者、共享槽位、Barrier 与读者分别是谁？

   写者 各warp lane[0] 共享 ： lane 0 barrier 等待 各lane 0 写完， 读者 warp[0] lane[0]

   写者 warp [0] lane[0] 共享 warp[0] lane[0] barrier 等待 warp[0]lane[0]写完 读者 block

7. 50 repeats × 100 launches 最终有几个 p95 样本？
