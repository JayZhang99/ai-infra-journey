   local_tid 是在block里的线程id 范围是 0 - blockDim

   global_tid 是在 grid 里的线程id 范围是 0 - threads -1

   data_index 是数据下标，和前面两个线程id没关系

3. 2 分：写出 Grid-stride 的初始值与步长。

   步长 GridDim * BlockDim

4. 2 分：写出 Baseline 和 Block 的 row 映射。

   Block 一个 Block处理一行  rows = blocks
