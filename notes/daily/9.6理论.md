3. 3 分：解释 TPOT、ITL，并写 E2E 近似公式。

   TPOT 指的是 每个Token 生成的时间间隔

   而 ITL 则是指客户端每个Token到达间隔，比TPOT 会多从模型到客户端的开销

   

4. 3 分：区分 QPS、tokens/s 与 Concurrency。

   QPS 指每秒处理的请求

   tokens/s input 是输入token

   output 是模型输出token速度

   Concurrency 是指每秒在处理的请求数

1. 3 分：KV block、block table 与逻辑/物理连续性。

   KV block 逻辑连续 物理不连续

   block table 即KV block 逻辑块和物理块的映射

   

2. 3 分：内部碎片与 block size tradeoff。

   Block size 大， 内部碎片多，浪费内存

   Block size 小，内部碎片小，但调度和状态维护开销大

3. 3 分：token、KV、sequence 三重准入检查。

   token ： 每一个iteration 可用 token 是否符合

   KV：Hkv是否大小符合

   sequence：用的block 数是否够

4. 3 分：长 Prefill 如何影响 ITL，Chunked Prefill 如何改善。

   长prefill 占据内存， 导致decode需要等待prefill，所以ITL p99增大

   chunked prefill 将长profill分割成多个chunk，避免decode一直等待prefill
