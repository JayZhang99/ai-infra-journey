### 必须订正的答案

1. Pre-Norm Decoder：

   h = x + MHA(RMSNorm(x))

   y = h + SwiGLU(RMSNorm(h))

2. RMSNorm：

   y = x / sqrt(mean(x^2, dim=-1, keepdim=True) + eps) * weight

   最后一维是每个 token 的特征维；eps 防止分母为 0；平方、mean 和 rsqrt 使用 float32 可降低半精度累计误差。

3. SwiGLU：

   gate = SiLU(gate_proj(x))，shape 为 [B,T,Dff]

   up = up_proj(x)，shape 为 [B,T,Dff]

   output = down_proj(gate * up)，shape 回到 [B,T,Dmodel]

   PyTorch Linear weight 的存储 shape 为 gate/up [Dff,Dmodel]，down [Dmodel,Dff]。

4. MHA：

   B=2、T=128、D=512、H=8 时，Dh=64。

   Q split [2,8,128,64]；scores [2,8,128,128]；context [2,8,128,64]；output [2,128,512]。

5. KV Cache：

   bytes = 2 * layers * batch * Hkv * sequence * head_dim * element_size

   开头的 2 表示 K 和 V；GQA/MQA 必须使用 KV Head 数 Hkv，而不是 Query Head 数 Hq。

## 6. 工程实现审查

### 已确认正确的实现

- RMSNorm：Parameter 注册正确；最后一维平方均值；float32 内部计算；输出恢复输入 dtype。
- SwiGLU：SiLU(gate_proj(x)) 与 up_proj(x) 逐元素相乘，再经 down_proj 回到 Dmodel。
- TinyFFNBlock：x + ffn(norm(x))，符合 Pre-Norm FFN Residual。
- MHA：Q/K/V 投影、拆 Head、缩放点积、Mask、Softmax、聚合 V、合 Head 与 out_proj 数据流完整。
- Cache：K/V prefix 与 suffix 均使用 expected 对象比较，旧自比较盲点已闭合。

### 独立诊断结果

- RMSNorm 零输入：输出有限且精确为 0。
- RMSNorm float16：输出保持 float16 且有限。
- SwiGLU：与展开的 F.linear reference 一致，全部 Parameter 获得梯度。
- TinyFFNBlock：与手工 composition 一致，全部 Parameter 获得梯度。

这些诊断证明实现具备正确性，但还不能替代仓库中可长期回归的 pytest 合同。

### 测试合同缺口

pytest 实际没有收集以下三个函数：

- tset_swiglu_matches_reference
- tset_swiglu_parameters_and_gradients
- tset_tiny_ffn_block_matches_compositino

其中前两个即使手动调用也会失败：

- SwiGLU reference：NameError，测试文件没有导入 torch.nn.functional as F。
- F.Linear 应改为 F.linear。
- y.square().mean.backward() 应改为 y.square().mean().backward()。
- composition 实现本身可通过，但函数名必须以 test_ 开头才会进入 pytest。

其他建议订正：

- test_rmsnorm_mathes_reference 改为 test_rmsnorm_matches_reference。
- constract、compositino、dimention 等拼写统一为 contract、composition、dimension。
- TinyFFNBlock.forward(self, x = torch.Tensor) 改为 forward(self, x: torch.Tensor)；当前写法把 Tensor 类当作默认参数，不是类型标注。
